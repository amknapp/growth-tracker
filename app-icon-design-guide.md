# GrowthTracker App Icon Design Guide

## Icon Concept
A simple, recognizable growth chart symbol that conveys child development tracking.

## Design Specifications

### Dimensions
- **Master Size**: 1024x1024px (required for app stores)
- **Format**: PNG with transparency OR solid background
- **Color Mode**: RGB

### Color Palette
- **Primary Blue**: #4A90E2
- **Secondary Purple**: #7B68EE
- **Accent Green**: #50C878
- **White**: #FFFFFF

### Design Elements

#### Option A: Growth Chart Line (Recommended)
```
Background: Gradient from #4A90E2 (top) to #7B68EE (bottom)
Symbol: White upward trending line with data points
Style: Minimalist, clean lines
```

#### Option B: Ruler with Growth Arrow
```
Background: Solid #4A90E2
Symbol: White vertical ruler with upward arrow
Style: Simple, iconic
```

#### Option C: Child Silhouette with Chart
```
Background: Gradient #4A90E2 to #7B68EE
Symbol: Simple child outline with small growth chart
Style: Friendly, approachable
```

## DIY Instructions (PowerPoint/Google Slides)

### Step 1: Create Canvas
1. Create new slide
2. Set slide size to 10" x 10" (or custom 1024x1024px)
3. Delete all text boxes

### Step 2: Background
1. Right-click slide > Format Background
2. Choose "Gradient Fill"
3. Type: Linear
4. Angle: 135°
5. Gradient stops:
   - Stop 1 (0%): #4A90E2
   - Stop 2 (100%): #7B68EE

### Step 3: Add Growth Chart
1. Insert > Shapes > Line
2. Draw an upward trending line (like a stock chart going up)
3. Make it white (#FFFFFF)
4. Line weight: 40-50px (thick enough to see)
5. Add 3-4 circular shapes along the line as data points
   - Circle size: 80-100px diameter
   - Color: White (#FFFFFF)

### Step 4: Export
1. File > Save As > PNG
2. Maximum quality
3. Save as "app-icon-1024.png"

## Design Tips

1. **Keep it simple**: Icon will be tiny on phone screens
2. **High contrast**: Must be visible on any background
3. **No text**: Icon should work without words
4. **Test at small sizes**: Shrink to 60x60 to see if still recognizable
5. **Avoid gradients on important elements**: Can look muddy when small
6. **Consider dark mode**: Test on dark backgrounds too

## What NOT to Do
❌ Complex illustrations (too detailed)
❌ Thin lines (invisible when small)
❌ Text or letters (hard to read)
❌ Photos (don't scale well)
❌ Too many colors (confusing)

## What TO Do
✅ Bold, simple shapes
✅ Strong contrast
✅ Memorable symbol
✅ Professional appearance
✅ Scalable design
